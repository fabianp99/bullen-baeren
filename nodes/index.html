Und was können Miner doch?

Mit mehr als der Hälfte der Rechenleistung (51 %-Angriff) könnten Miner Transaktionen blockieren oder eine eigene, frische Zahlung zurückdrehen. Das wäre extrem teuer. Regeln ändern, also mehr Coins erzeugen oder fremde Coins nehmen, können sie trotzdem nicht.

🗄️ Full NodeLädt und prüft die ganze Blockchain.
✂️ Pruned NodePrüft auch alles, löscht aber alte Blöcke.
📱 Light-ClientPrüft nur Teile, vertraut anderen Nodes.

Merke: Miner schlagen Blöcke vor, Nodes prüfen die Regeln.

Und können Nodes schummeln?

Eine Node ist nur ein Computer mit der Bitcoin-Software. Was passiert, wenn jemand seine Node so verändert, dass sie lügt?

Sechs Nodes, jede mit ihrer eigenen Kopie der Blockchain. Tipp auf den Knopf.

Und wie ändern sich die Regeln?

Ein Update geht nur, wenn Nodes freiwillig mitmachen. Soft Fork: Regeln werden strenger, alte Nodes bleiben kompatibel. Hard Fork: Regeln werden lockerer, alte Nodes lehnen ab, die Kette kann sich spalten.

    Wer entwickelt Bitcoin eigentlich?

    👩‍💻 Open SourceDer Code ist öffentlich. Jeder kann ihn lesen, prüfen und Verbesserungen vorschlagen. Die bekannteste Software heißt Bitcoin Core, gepflegt von Freiwilligen und gesponserten Entwicklern weltweit.
    📝 Vorschläge (BIPs)Größere Änderungen werden als Bitcoin Improvement Proposal aufgeschrieben und oft jahrelang öffentlich diskutiert und getestet.
    🗳️ Die Nodes entscheidenEntwickler können nichts erzwingen. Erst wenn Nutzer ihre Node aktualisieren und Miner mitziehen, wird eine Änderung zur Regel. Deshalb ist Bitcoin bewusst langsam.
