Jede Zahlung ist ein kleines Programm

Bitcoin hat keine Konten. Stattdessen hängt an jedem Betrag ein kleines Schloss aus Code, das Script. Wer ausgeben will, liefert den passenden Schlüssel. Die Nodes rechnen beides auf einem Stapel durch: Steht am Ende „wahr“ oben, ist die Zahlung gültig.

Wähle ein Schloss und führe es aus

Warum so einfach?

Script kann absichtlich keine Schleifen und nichts aus dem Internet laden. So kann jede Node jedes Schloss in Millisekunden prüfen, und niemand kann das Netz mit Endlos-Programmen lahmlegen. Trotzdem reicht es für Mehrfach-Unterschriften, Zeitschlösser, Erbschafts-Lösungen und Lightning.

Das solltest du dir merken

Schloss + SchlüsselJeder Betrag hat ein Schloss-Script. Zum Ausgeben liefert man das passende Schlüssel-Script.
Der StapelWerte werden oben draufgelegt und Befehle nehmen sich die obersten. Am Ende muss „wahr“ oben liegen.
Multisig2 von 3 Schlüsseln müssen unterschreiben. Ideal für Familien, Firmen und Erbschaft.
ZeitschlossGeld kann erst ab einem bestimmten Block ausgegeben werden. Wichtig für Lightning und Erbschaft.
