Das Kopier-Problem

Ein Foto kannst du so oft kopieren, wie du willst. Wäre Geld eine einfache Datei, könntest du es auch kopieren und zweimal ausgeben. Genau dieses Problem musste Bitcoin lösen.

Versuch, eine Münze zweimal auszugeben

Du hast 1 digitale Münze. Du schickst sie gleichzeitig an Anna und an Ben. Wähle, wer aufpasst:

Die Lösung in einem Satz Verbinde …

Statt einer Bank führen Tausende Computer dasselbe Kassenbuch. Jede Zahlung wird von allen geprüft. Die Reihenfolge legen Miner fest, indem sie Zahlungen in Blöcke packen. Was zuerst im Block steht, gilt. Die zweite Ausgabe derselben Münze lehnt jeder ab.

Deshalb gibt es die Blockchain (das gemeinsame Kassenbuch), Mining (die Reihenfolge) und Nodes (die Prüfer). Wie das genau funktioniert, lernst du in Welt 6. Alles andere baut darauf auf.

Das solltest du dir merken

Kopieren ist das ProblemDigitale Dinge lassen sich beliebig kopieren. Geld darf man aber nur einmal ausgeben.
Bank als AufpasserBisher löste das eine Bank. Sie führt das Kassenbuch, kann aber auch sperren oder Fehler machen.
Ein Kassenbuch für alleBei Bitcoin hat jede Node eine Kopie und prüft jede Zahlung selbst.
Was im Block steht, zähltZwei widersprüchliche Zahlungen können kurz gleichzeitig im Netz sein. Gültig wird die, die ein Miner in einen Block packt. Mit jedem weiteren Block wird das sicherer.
